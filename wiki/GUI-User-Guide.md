# 🖥️ GUI 사용자 가이드 (GUI User Guide)

**`gui_app.py`**는 작업자와 엔지니어가 직관적으로 검사를 수행하고 관리할 수 있는 PySide6 기반의 데스크톱 GUI 애플리케이션입니다.

---

## 1. 화면 구성 (Layout Overview)

GUI 화면은 크게 5개의 주요 영역으로 구성되어 있습니다:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ ① 메뉴 바 (Menu Bar): 레시피(Recipe), 시험(Test), 설정(Settings), 모드(Mode)   │
├─────────────────────────────────────────────────────────────────────────────┤
│ ② 상단 툴바: 모드 표시, 레시피 지문, DUT S/N 입력, 모의 모드, 수율, 성적서 버튼  │
├──────────────────────┬──────────────────────────────────────────────────────┤
│ ③ 카드 팔레트        │ ④ 테스트 카드 대시보드 (Test Card Dashboard)           │
│    (Card Palette)    │ ┌──────────────────────────────────────────────────┐ │
│ ┌──────────────────┐ │ │ ⚡ PPK2 Config 카드                ❓ ⚙️           │ │
│ │ 🔍 검색...       │ │ │    Source Meter | 3000 mV | 전원 ON              │ │
│ └──────────────────┘ │ ├──────────────────────────────────────────────────┤ │
│ ⚡ PPK2 Config     │ │ 🔌 Serial Config 카드              ❓ ⚙️           │ │
│ 🔌 Serial Config   │ │    COM4 | 115200 bps | Flow: RTS/CTS               │ │
│ 🔋 PPK2 Idle Current │ ├──────────────────────────────────────────────────┤ │
│ 🧩 Bluetooth DTM   │ │ 🔋 PPK2 Idle Current 측정       ⬆ ⬇ ❓ ⚙️ ▶ 🗑      │ │
│   (드래그하여 추가)    │ │    소요시간: 3.5s | 기준: 1.5 ~ 3.5 uA            │ │
│                      │ │    ✅ PASS (Avg: 2.145 uA)                       │ │
│                      │ └──────────────────────────────────────────────────┘ │
├──────────────────────┴──────────────────────────────────────────────────────┤
│ ⑤ 하단 상태 표시줄: 진행률 프로그레스바, 총 실행 횟수, 스테이션 및 작업자 정보 │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 카드 관리 및 배치 (Card Management)

### 1) 카드 추가 (Add Cards)
- 좌측 **카드 팔레트**에서 원하는 검사 카드를 마우스로 끌어서 우측 **대시보드 영역**에 드롭합니다.
- 팔레트 상단의 검색창(`검색...`)을 통해 카드 이름, 설명, 태그로 빠르게 필터링할 수 있습니다.
- 카드 코드가 수정되거나 새로운 모듈 폴더가 추가되었을 경우 팔레트 하단의 `🔄 카드 새로고침` 버튼을 누르면 프로그램을 재시작하지 않고도 즉시 다시 로드됩니다.

### 2) 카드 조작 버튼
대시보드에 배치된 각 카드의 우측 상단에는 다음과 같은 제어 버튼이 있습니다:
- `⬆` / `⬇` : 대시보드 내에서 실행 순서를 위/아래로 이동합니다. (설정 카드는 자동으로 최상단에 고정됩니다)
- `❓` : 해당 카드의 **결선 가이드 및 상세 도움말** 창을 표시합니다.
- `⚙️` : 해당 카드의 **검사 판정 기준값(Criteria)**을 설정하는 다이얼로그를 엽니다.
- `▶` : 해당 카드만 **단독으로 즉시 실행**합니다. (공용 계측기 세션이 자동으로 연결 및 해제됩니다)
- `🗑` : 해당 카드를 대시보드에서 제거합니다.

### 3) 도움말 및 결선 가이드 다이얼로그 (`❓`)
- 각 카드의 `❓` 버튼을 누르면 모듈 폴더 내의 `setup_guide.png` 이미지와 다국어 설명문이 담긴 창이 열립니다.
- 창의 크기를 늘리거나 줄여도 결선 가이드 이미지가 비율을 유지하며 자동으로 부드럽게 스케일링됩니다.

## 3. 글로벌 장비 연결 툴바 및 계측기 설정 (Hardware Connection)

### 1) 상단 글로벌 장비 연결 툴바 (Global Device Toolbar)
DUT와의 UART 직렬 통신은 개별 카드가 아닌 **메인 화면 상단 전역 툴바**에서 직관적으로 제어합니다.
- **🔌 Target DUT Control Port 드롭다운**: 연결된 USB 가상 COM 포트를 자동 감지하여 목록화합니다. 직접 포트 경로를 입력할 수도 있습니다.
- **통신 속도 (Baud Rate)**: 기본 115200 bps부터 고속 921600 bps까지 선택 가능합니다.
- **🔄 새로고침 버튼**: USB 케이블 재연결 시 즉시 포트 목록을 갱신합니다.
- **⚡ 연결 확인 버튼**: 현재 선택된 포트가 정상 오픈되는지 즉시 진단하여 녹색/적색 뱃지로 상태를 표시합니다.
- **📟 시리얼 터미널 버튼**: 언제든지 즉시 대화형 시리얼 터미널 창을 열어 DUT의 부팅 로그를 모니터링하거나 명령어를 전송할 수 있습니다.
- **전역 상속**: 시리얼이 필요한 모든 검사 카드(`serial_log_monitor`, `dtm_tx_test` 등)는 상단 툴바에 선택된 포트와 속도를 자동으로 상속받습니다.

### 2) 계측기 설정 카드: PPK2 Config 카드 (`config_ppk2_interface`)
Nordic PPK2 전원 공급 및 정밀 전류 측정 세션을 관리하며, 대시보드의 최상단에 자동으로 배치됩니다.
- PPK2 측정이 필요한 카드(`ppk_idle_current`, `ppk_dtm_tx_power` 등)를 대시보드에 드롭했을 때, 대시보드에 PPK2 Config 카드가 없다면 원클릭 추가 안내 팝업이 표시됩니다.

## 4. 동작 모드: 운용자 vs 엔지니어 (Operation Modes)

상단 툴바의 모드 표시 뱃지 또는 상단 메뉴 `모드(Mode) -> 모드 전환...`을 통해 전환할 수 있습니다.

### 1) 엔지니어 모드 (Engineer Mode) - 기본값
- 모든 기준값(Criteria), 포트 설정, 시퀀스 순서, 카드 추가/삭제를 자유롭게 수정할 수 있습니다.
- 새로운 레시피를 생성하거나 기존 레시피를 수정하여 파일(`.recipe.json`)로 내보낼 수 있습니다.
- 모의 시뮬레이션(Mock Mode)을 켜고 끌 수 있습니다.

### 2) 운용자 모드 (Operator Mode) - 양산 라인용
- 생산 현장의 작업자가 임의로 판정 기준값을 변경하여 오검사/불량 유출이 발생하는 것을 원천 차단합니다.
- 카드의 `⚙️` 설정 버튼이 비활성화되며, 기준값 편집 창이 열리지 않습니다.
- 카드 순서 변경, 삭제가 제한되며, 사전에 엔지니어가 배포한 고정 레시피로만 검사를 수행할 수 있습니다.
- **모드 전환 암호 (Passcode)**:
  - 운용자 모드에서 엔지니어 모드로 복귀하려면 설정된 비밀번호를 입력해야 합니다.

## 5. 시험 실행 및 결과 확인 (Execution & Reports)

### 1) 실행 제어 버튼
- **`▶ 전체 시험 실행 (Run All)`**: 대시보드에 나열된 순서대로 카드를 일괄 실행합니다. 실행 중에는 버튼이 `🛑 테스트 중지 (Stop)`로 변경되어 즉시 취소할 수 있습니다.
- **반복 횟수 설정 (`🔁 n회`)**: 전체 시퀀스를 지정한 횟수만큼 반복 수행합니다.
- **실패 시 시퀀스 중단 (`menu_stop_on_fail`)**: 한 카드라도 FAIL이 발생하면 즉시 시퀀스를 멈춥니다.
- **실패 시 반복 중단 (`menu_stop_batch_on_fail`)**: 반복 검사 도중 FAIL 발생 시 다음 반복으로 넘어가지 않고 멈춥니다.
- **초기화 버튼 (`🗑🧹`)**: 성적서 버튼 좌측의 쓰레기통 아이콘 버튼을 클릭하면 이전 검사 결과와 로그를 시험 전 대기(PENDING) 상태로 깨끗하게 리셋합니다.

### 2) DUT 시리얼 번호 입력 (`🏷️ DUT`)
- 검사 전 DUT 버튼을 누르거나 바코드 리더기를 통해 제품 일련번호(Serial Number)를 스캔합니다.
- 시리얼 번호는 검사 성적서 및 추적성 로그(`trace/`)에 기록되어 개체별 이력 관리가 가능해집니다.

### 3) 성적서 및 결과 리포트 (`📊 성적서`)
- 검사가 완료되면 종합 결과 창이 나타납니다.
- **`🌐 브라우저로 보기`**: 아름답고 인터랙티브한 반응형 HTML 보고서를 기본 웹 브라우저로 즉시 띄웁니다.
- **`🌐 HTML 저장`** / **`📄 TXT 저장`**: 성적서 파일을 원하는 경로에 저장합니다.
- **일일 수율(Yield) 통계**: 상단 툴바에 오늘 날짜 기준 `PASS 수 / FAIL 수 / 전체 수율(%)`이 실시간으로 집계되어 표시되며, `수율 카운터 초기화` 메뉴를 통해 언제든 초기화할 수 있습니다.

## 6. 다국어 설정 및 상태 보존

- 상단 메뉴 `설정(Settings) -> 🌐 언어(Language)`에서 **한국어(KO), English(EN), 日本語(JA), 中文(ZH)** 중 원하는 언어를 선택할 수 있습니다.
- 변경된 언어, 창의 크기 및 위치, 대시보드에 배치된 카드 및 카드별 설정값은 `dashboard_layout.json`에 영구 보존되어, 프로그램을 종료했다가 다시 실행해도 이전 상태 그대로 복원됩니다.
